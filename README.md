# Simple BMI Calculator 🧮

A lightweight and minimalist Body Mass Index (BMI) calculator web application built with HTML, CSS, and JavaScript. It helps users quickly calculate their BMI based on weight in kilograms and height in centimeters, and instantly classifies their health status.

---

## Features ✨

* **Real-time Calculation:** Instantly computes BMI using standard health formulas.
* **Health Categorization:** Automatically classifies results into Underweight, Normal weight, Overweight, and Obese.
* **Input Validation:** Ensures correct positive values are entered before processing.
* **Clean & Responsive UI:** Designed with a modern, centered card layout for a smooth user experience.

---

## Tech Stack 🛠️

* **HTML5:** Page structure and input forms.
* **CSS3:** Styling, card shadow effects, and responsive layout.
* **JavaScript (Vanilla):** BMI formula execution, conditional logic, and DOM manipulation.

---

## How to Run Locally 🚀

1. **Clone or Download** this repository to your local machine.
2. Open the project folder.
3. Double-click on the `index.html` file (or open it using any modern web browser like Chrome, Edge, or Firefox).

---

## BMI Categories Reference 📊

| BMI Range | Category |
| :--- | :--- |
| **Below 18.5** | Underweight |
| **18.5 – 24.9** | Normal weight |
| **25.0 – 29.9** | Overweight |
| **30.0 and above** | Obese |
